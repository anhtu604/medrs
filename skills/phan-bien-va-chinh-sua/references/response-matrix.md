# Point-by-point response matrix

One row corresponds to one atomic reviewer request. Split multi-part comments while retaining the parent comment. Required fields are comment ID, reviewer/round, verbatim comment, source locator, classification, decision, rationale/evidence, response text, changed artifact, exact change locator, artifact hash, downstream dependencies and re-review state.

Responses lead with the decision and factual action. Quote or summarize only enough changed text to locate it; the manuscript remains authoritative. If no change is made, say so directly and support the decision. Never write “changed as requested” without an artifact and locator. Never claim agreement while silently implementing a different change.

Track dependencies across title, abstract, Methods, Results, Discussion, tables, figures, supplement, registration, disclosures and response letter. Numerical updates use stable claim IDs rather than text search alone. The matrix remains open while any commitment lacks a verified artifact, any propagation mismatch remains, or an affected gate has not been rerun.
