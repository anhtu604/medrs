# Assembly workflow

Order work by dependency, not by page order: confirm Passport and target profile; freeze objectives and Methods state; verify analysis artifacts; draft Results; draft Introduction and literature synthesis; approve the Discussion Blueprint and draft Discussion; draft conclusions; create the abstract last; assemble; run the document-wide style gate; validate; revise and revalidate.

Each section artifact retains locale/target versions, Passport and source-ledger dependencies, claim–evidence rows, markers, author approvals, preflight result, and hash. A changed objective, method, denominator, estimate, source, target profile, or author decision invalidates every dependent section. A prose-only edit invalidates its section style audit and document consistency, not unrelated scientific verification.

Assembly does not authorize reordering against a journal or institution profile. It emits a restructuring request. It does not apply fonts, margins, fields, pagination, or heading styles. Conflicts become `BLOCKED_CONFLICT` with both values and source locations.
