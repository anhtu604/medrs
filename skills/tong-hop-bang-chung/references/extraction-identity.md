# Extraction identity and original-source trace

For every extracted estimate record the original study/source/locator, outcome definition, group/reference, time, analysis set, effect measure, adjustment and outcome-available N. Recruitment N does not fill a missing outcome N. Check row/column headers and footnotes together before interpreting a numeric cell; an apparent association can be an adjacent group, another follow-up or an adjusted rather than unadjusted model.

Use the extraction checks in [../../phan-tich-so-lieu/scripts/statistics_policy.py](../../phan-tich-so-lieu/scripts/statistics_policy.py), with the shared [result identity contract](../../phan-tich-so-lieu/references/result-identity-contract.md). Missing identity fields remain unresolved; do not reconstruct denominators from context. A machine check verifies field consistency, not that the copied values match the paper: compare each record with the actual source/table/footnote and preserve its locator.

Secondary review tables are discovery pointers, not confirmed original-study results. Retrieve the original source where lawful; if only abstract/secondary material is available, retain that access ceiling and qualify the extraction. Never fill unavailable Methods/Results from familiarity with the topic. Keep unresolved original sources in the evidence-needs ledger, not as invented citations.
