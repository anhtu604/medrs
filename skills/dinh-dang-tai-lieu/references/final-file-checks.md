# Saved Word artifact checks

Load the latest author-confirmed style decisions alongside the institution/journal profile: separate body, table, table footnote, caption, TOC/list and bibliography font/size/line-spacing; digit/decimal/dash conventions; alignment and orientation. They are distinct roles: a table note may be 11 pt single-spaced while table text and TOC are 14 pt. Do not silently restore a previous style carrier's defaults.

Table prose is left aligned and numeric columns can be centered per project conventions; justified cell paragraphs often create excessive internal spaces. Preserve merged cells and two-tier headers. Keep caption with the header/first meaningful row, repeat actual header rows, and keep comparison pairs together where needed. Let long tables break where content permits. Do not chain keep-with-next over the entire table by a universal row-count cutoff, which creates large blank areas. Avoid splitting compact numeric cells; inspect wrapped means/SD and negative intervals. Do not introduce landscape sections automatically when the author wants portrait.

After a table split/removal update observations, captions, SEQ/REF, body references, lists, symbols, embedded chart values and appendices. Scan saved text for glued references, obsolete labels and unexpanded symbols. Compare abbreviation-list entries with manuscript usage in both directions, excluding units, statistical notation and bibliography titles. Review raster labels/embedded spreadsheets separately if XML extraction cannot reach them.

Check Zotero metadata as well as field preservation. Library repair has separate authorization; read-only library access never changes records. Do not patch regenerated bibliography display as a lasting fix for duplicated Internet labels, PMID clutter or case/year errors: record the item needing metadata repair, then refresh and inspect after an authorized repair.

Mechanical validation reports actual style definitions plus paragraph/run overrides throughout body, cells and headers. Final validation needs the refreshed/saved file hash, backend update log, render artifacts and a visual report naming inspected pages. A renderer command succeeding, Word opening, or live fields surviving does not alone establish content/presentation acceptance. If refresh/render is unavailable, deliver the draft with that check unperformed.
