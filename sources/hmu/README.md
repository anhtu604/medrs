# HMU source acquisition

This directory records official sources for the Hanoi Medical University document-profile workstream. Checksums and official download URLs preserve provenance. The source binaries are deliberately absent from the public repository because their redistribution terms are unknown.

Maintainers may place lawfully obtained copies under `snapshots/` using the registered filenames. A local copy is accepted only when its SHA-256 matches `source-register.yaml`; the directory is ignored by Git and release packaging.

The official HMU page “Quy trình và biểu mẫu dùng cho bảo vệ luận văn sau đại học (cập nhật năm 2026)” links directly to the DOCX “Yêu cầu đối với luận văn”. The downloaded DOCX and the author-supplied copy have the same SHA-256 checksum, so the authoritative-access milestone is complete. This confirms provenance and current official access; it does not silently infer a document number or effective date that the source does not state.

Decision 3589/QĐ-ĐHYHN and the later defense notice support the defense-process workflow. Encoding the presentation requirements into an executable HMU profile and passing its document fixtures remain Slice 4 acceptance work.
